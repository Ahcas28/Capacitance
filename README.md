Code Matlab de calcul de matrice de capacitance généralisée. 
Résolution de l'équation de Helmholtz avec amortissement dans la limite haut contraste pout un système tridimensionnel de résonateurs de Helmholtz sous-longueur d'onde.
Résolution dans différentes géométries. 
Possibilité d'introduire des défauts dans la géométrie et les paramètres.
